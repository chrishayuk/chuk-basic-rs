# Learning BASIC with chuk-basic

The tutorial has moved to [`tutorial/`](../tutorial/01-introduction.md): 22
chapters, from `PRINT "HELLO"` to matrices, the BASIC of 1964 and compiling
to WebAssembly.

Start at [chapter 1](../tutorial/01-introduction.md), or go straight to the
[reference](../tutorial/22-reference.md).

Every program in it is followed by what it prints, and
`python3 tutorial/check_tutorial.py` runs them all and compares.
